# luc-todo — current state and architecture

_Snapshot: 1 Nov 2026 (v1044). Repo `Levo54321/todo`, live at https://luc-todo.vercel.app._

## 1. Big picture
```
iPad 2 (iOS 9) / iPhone  --XHR-->  /api/*.js (Vercel Node, dub1)  --RPC-->  Supabase Postgres (security-definer functions)
        |                                   |--> Apple iCloud CalDAV  (api/cal.js)
        |                                   |--> Google Calendar OAuth (api/gcal.js)
        |                                   `--> Open-Meteo / iCal feed (api/glance.js)
```
Only the API layer holds the Supabase key. The browser holds the access token (localStorage) and sends it as `x-todo-token`.

## 3. Data model
`todos` (RLS on, accessed only by RPCs). Key fields: `list` personal/work; `category` is the project for Work; `prio` 0-3; flags `must`, `quick`, `low`, `blocked`, `paused`; recurrence `recur` (daily, weekdays, weekly, fortnightly, monthly, yearly) with `recur_until` and `series_id`; session tasks use `is_session` + `items` jsonb; `plan_date/plan_order` drive day planning; calendar sync fields `cal_uid/etag/sig`; `pproject_id` (nullable) links a Personal task to a Personal Project; `pp_backlog` keeps such a task on the project page only (Backlog).
Other tables: `personal_projects(id,name,status,meta,created_at,updated_at)` (status in_progress/live/paused/not_pursued/shut_down, 'active' accepted as in_progress; names unique ignoring case; `meta` jsonb: sites [urls], links [{l,u}], vercel, supabase, github, desc, started, target, icon), `personal_project_events(project_id,at,kind,text)` (activity log, written by `pproj_save` and `todo_update`), `app_config(key,value)`, `budget_entries(entry_date,kind,amount)`, `saver_images`. Shop tables (`shop_*`) and the `shop` config key share the database but belong to holmlodge-shop (a separate app with its own repo/project); this app never reads or changes them.

## 4. API surface
`/api/todos` (GET list, POST add/quick-add, PATCH, DELETE; plan ordering), `/api/pause`, `/api/projects` (Work), `/api/pprojects` (Personal Projects), `/api/history`, `/api/budget`, `/api/cal`, `/api/gcal`, `/api/glance`, `/api/ics` (event, task feed, bill feed), `/api/saver`, `/api/settings`.
Env vars (Vercel only): `SUPABASE_URL`, `SUPABASE_KEY`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`; optional `GLANCE_LAT/LON/PLACE`, `CAL_ICS_URL`, `VERCEL_TOKEN` (read-only; live deploy dots on My projects).

## 5. Key data flows
- **Quick add** (Shortcut or app): `POST /api/todos {text}` -> shorthand parsed server-side (days, months, times, list/category) -> `todo_add`.
- **Work ordering**: client `cmpWork` sorts the Work column; `Ot/At` maps from `setProjects` break ties by project order; board order saved via `PATCH /api/projects?id`.
- **Pause**: `POST /api/pause?id {paused,on}` -> `todo_pause`. Pausing stamps `paused_at`; resuming adds elapsed whole days to `due_date` and accumulates `paused_secs`. Paused tasks are excluded from Overdue/counts and from `todo_history` durations. Resume then best-effort re-syncs Apple/Google calendars.
- **Calendars**: personal timed tasks -> Apple CalDAV (only events with UID suffix `@luc-todo` are ever touched). Timed Work tasks -> Google Calendar when the editor choice is "yes" (per-task choice stored via `/api/gcal` `sched`).
- **Personal Projects** (v1041): separate from Work projects and from the Personal `category` label (which stays a free label driving chips/filters). `GET /api/pprojects` -> `pproj_list` (counts incl. `done_old` = finished >7 days ago, since `todo_list` only returns the last 7 days of done tasks); `POST`/`PATCH` -> `pproj_save`; task link via `PATCH /api/todos {pproject_id}` (or `POST /api/todos {title, pproject_id}`). `todo_update` keeps `pproject_id` only for Personal tasks (cleared on a move to Work) and copies it to the next copy of a repeating task. In `core.js`, `isShelved(t)` = open Personal task whose project is not Active: treated like a paused Work task (out of Overdue, badges, stats, category counts, Today's order, review nudges, Insights open/behind) and listed in a collapsed "On-hold projects" group. Rail item "My projects" sits under Personal; the Work board keeps "Projects".
- **My projects v2** (v1042): `GET /api/pprojects?deploy=1` asks the Vercel API (env `VERCEL_TOKEN`) for the latest production deploy of each project whose `meta.vercel` is `https://vercel.com/<team>/<project>`, cached ~5 min per warm function; green READY, orange building/queued, red error/cancelled/blocked, grey unknown. Saving a new site link makes the server look up the site's apple-touch-icon/icon once (stored as `meta.icon`; the browser falls back to the first letter). `GET ?events=<id>` returns the activity log. v1043: statuses In progress / Live (both count normally; shelved = paused, not_pursued, shut_down via `PP_SHELF` in core.js), several websites and labelled links, a Vercel project picker (`GET ?vercel=1` lists the token's projects; `GET ?vercel=<team>/<name>` returns production domains minus git/team aliases and redirects, plus the GitHub repo from `link`), deploy dot PAUSED (hollow ring) when the Vercel project has `paused: true` or its first website answers 503 `x-vercel-error: DEPLOYMENT_PAUSED`, and a collapsible Activity section (remembered in localStorage `ppAct`). Backlog: `inBacklog(t)` in `core.js` takes the task out of `inMode`, so it never appears in the Personal list, badges, counts, Today's order or Insights; it shows only on the project page ("→ Add to my list" / "→ Back to backlog", data-act `ppbl`). Project forms use class `ppadd` (not `bdadd`, which board.js's submit handler owns).
- **My projects layout** (v1044): wider than 760px the view is fixed-height: `pprojects.js` adds class `ppfix` to `#vPprojects`, which switches the outer `.scrollview` to `overflow:hidden`, and `layout()` sets px heights from `window.innerHeight` (never `vh`) on every paint, resize and orientation change. Board: `.bdcols` is the only sideways scroller; each open lane wraps its cards in `.pplane` (own vertical scroll). Project page: `.pptop` (All projects bar) fixed, `.ppside` frozen at full height (scrolls only if its own content is taller, e.g. Edit details), `.ppmain` is the only scrolling column. Scroll positions (lane tops, sideways offset, page columns) are kept across repaints. 760px and narrower: stacked, page scrolls as before. Vercel picker: the details draft remembers which websites (`draft.vsites`) and GitHub link (`draft.vgh`) the picker filled in; a new pick replaces those and keeps hand-typed ones (for a saved project these are worked out by asking `?vercel=` for its current project when the form opens). Icon lookup returns nothing when the site cannot be read (503/paused/timeout) and the API then keeps the stored `meta.icon`.
- **Shopping**: removed from this app on 1 Nov 2026 (v1040). The list lives only in holmlodge-shop.vercel.app.

## 7. Known nuances
- **Config keys are whitelisted** in `cfg_get`/`cfg_set` (`db/setup13.sql`): budget, caldav, caldav_state, saver, shop, gcal, projects. A new key needs a migration that edits both lists.
- `todos.category` (the project name) is capped at 40 characters; `title` at 500.
- `todos.created_at/updated_at` predate `db/setup01.sql`; rebuilding the database from `db/` alone would need the base `todos` table first.
- `todo_update` does not clear `paused` when a task is marked done (history handles it); check board/list code if a done task ever shows as paused.
- `db/setup01.sql` holds a placeholder for the access-token hash. Never commit the real hash.
- Repo `public/js` is readable source; earlier manual deploys were terser-minified. Cache buster `?v=` must be bumped in `build.py` args when JS/CSS change.
- Vercel MCP file-content reads truncate at ~2 KB; get source from the repo instead.
- Pause/Blocked/board features are mock-tested only; not yet exercised on physical iPad 2.
- `meta.icon` is a link to the project's own site, so a paused/down site cannot show its icon even when stored. Stored icon copies come with custom icons (Deploy 4 of the My projects plan).
- The Work board's lane lists still use `max-height: calc(100vh - 290px)`; My projects no longer does (JS heights).
- Test folders (t8-t12), old index versions and `.token` are intentionally not in the repo.
- Time zone is fixed to Europe/London in `api/todos.js`.
