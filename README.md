# luc-todo

Personal to-do system (Personal + Work lists, Projects board, Insights, Budget, Shopping list).
Static ES5 frontend (built for an iPad 2 on iOS 9.3.5 and an iPhone) + Vercel Node functions + Supabase.

- `public/`  static site (index.html is generated by `tools/build.py` from `shell.html`)
- `api/`     Vercel serverless functions (one per endpoint, e.g. `/api/todos`, `/api/pause`)
- `db/`      Supabase SQL migrations, run in order (`setup01.sql` ... `setup13.sql`)
- Secrets live in Vercel env vars only; see `.env.example`.

Rules: ES5 only in `public/js` (no arrow functions, let/const, grid, sticky).
Deploys: push to `main` -> Vercel production.

Deploys automatically from main via Vercel (project: luc-todo).
